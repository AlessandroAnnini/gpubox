When

A short rent for work you already have

Use gpubox when the script is yours and you need a GPU for a while, then nothing left running.

Smoke-test an offer

List, rank, create, run nvidia-smi, destroy. Live check 2026-09-19: RunPod NVIDIA RTX A4000 at $0.17/hr. Created, ran, destroyed.

Run a command you have

Your train script, llama.cpp, or a ComfyUI workflow. gpubox waits for SSH and tears the box down. It does not start the job for you.

Copy, run, copy back

upload a script or weights, run, download a log or checkpoint, destroy.

Start

List, rank, create, SSH, run, destroy

This is the whole product. The library does not start your training job for you.

from gpubox import LaunchSpec, OfferQuery, connect, rank_offers, wait_until_login

cloud = connect("runpod")
offers = rank_offers(cloud.list_offers(OfferQuery(gpu_names=["NVIDIA RTX A4000"])))
box = cloud.create(offers[0].id, LaunchSpec(image="ubuntu:22.04", disk_gb=50))
try:
    inst = wait_until_login(cloud, box)
    cloud.run(inst.id or box, "nvidia-smi")
finally:
    cloud.destroy(box)
from pathlib import Path

cloud.upload(box, Path("weights.gguf"), "/workspace/weights.gguf")
cloud.run(box, "./llama-cli -m /workspace/weights.gguf -p hello")
cloud.download(box, "/workspace/out.log", Path("out.log"))
cloud.destroy(box)

uv run --project . examples/rent.py runs the smoke-test loop on FakeCloud. No wallet. For a real box: GPUBOX_PROVIDER=runpod python examples/rent.py. Keys stay in the environment.

PyPI is later, on purpose. Pin the git URL until 0.x settles.

uv add "gpubox[all] @ git+https://github.com/AlessandroAnnini/gpubox"
# or: pip install "gpubox[vast] @ git+https://github.com/AlessandroAnnini/gpubox"

Loop

One box at a time

create returns an instance id (str). Keep that id. There is no Box type. wait_until_ssh and wait_until_login both return Instance. They are helpers, not Protocol methods.

flowchart TD list["list_offers"] --> rank["rank_offers"] rank --> create["create"] create --> banner["wait_until_ssh"] banner --> login["wait_until_login"] login --> run["run or copy"] run --> destroy["destroy"]

List offers on one provider, rank that list, create the first id, wait for the banner then login, run or copy, then destroy.

wait_until_ssh polls status() until ssh_open is true (TCP banner SSH-). wait_until_login then polls ssh … true. After box = cloud.create(...), keep box and use try / finally: destroy. rent still always destroys. status() never reads or writes /workspace/READY. Pass that probe in LaunchSpec.start_command if you want it. Boot-watch and stuck-after-pull timers stay in the caller.

Providers

Same Protocol, native ids

connect("runpod") after .env is valid. Empty api_key or ssh_key means env. GPU name strings stay in the vendor spelling.

RunPod live

SKU catalog. Offer ids are gpu|SECURE or gpu|COMMUNITY. Filter community with OfferQuery(raw="COMMUNITY"). Private key path: ssh_key= or RUNPOD_SSH_KEY. Put the matching .pub on the RunPod account.

Vast

Marketplace. GPU names such as RTX_4090. Adapter is shipped; not in the live receipt. Key: VAST_API_KEY.

Lambda

SKU catalog. Offer ids are instance_type|region. Adapter is shipped; not live-proven. Key: LAMBDA_API_KEY. SSH key from LAMBDA_SSH_KEY.

connect("fake") returns FakeCloud for tests. connect("memory") is the same object. Unknown names raise ValueError. Missing keys raise AuthError.

RunPod SSH Put the public key on the RunPod account (Settings → SSH keys). That is not RUNPOD_SSH_KEY. RUNPOD_SSH_KEY is the local private-key path. ensure_ssh_key(cloud) reads the matching .pub and appends it; it does not replace the list. If the vendor call cannot append, it raises AuthError — add the key in the console. A missing file or Permission denied (publickey) is also AuthError — the instance is already running.

Names RTX_4090 and NVIDIA GeForce RTX 4090 are not the same id. Do not merge lists across clouds.

Rank

Arithmetic on one list

rank_offers is a function, not a Protocol method. It does not call the network and it does not pick a cloud.

rank_offers(
    offers,
    price_weight=1.0,
    reliability_weight=0.0,
    disk_weight=0.0,
)

Score is price_weight * price_per_hour - reliability_weight * reliability - disk_weight * disk_space. Missing or non-finite reliability and disk count as 0. Non-finite price sorts last. Lower score wins. The sort is stable. Defaults rank by price only.

CLI

A thin wrapper around the same loop

gpubox --version prints the installed pin and does not require -p. Subcommands do.

gpubox --version
gpubox list -p runpod --gpu "NVIDIA RTX A4000" --raw COMMUNITY --rank
gpubox rent -p runpod --gpu "NVIDIA RTX A4000" --cmd nvidia-smi
gpubox status -p runpod INSTANCE_ID
gpubox destroy -p runpod INSTANCE_ID
CommandWhat it does
listPrint id, GPU name, price. --rank sorts first.
rentRank, create the first offer, wait for SSH, run --cmd, always destroy.
statusPrint id, provider status, ssh_open.
destroyDestroy that id.

Shared flags: -p/--provider, --api-key, --ssh-key. Keys also come from VAST_API_KEY, RUNPOD_API_KEY, LAMBDA_API_KEY, RUNPOD_SSH_KEY, and LAMBDA_SSH_KEY. rent defaults: image ubuntu:22.04, disk 16 GB, timeout 300s, command nvidia-smi. If SSH or the command fails, it still destroys and exits 1.

Errors

One base class, typed failures

Catch GpuBoxError for any library failure. Vendor HTTP leaks are wrapped.

ExceptionWhen

SshNotReadySSH host or port not published, banner not up, or wait timed out

Tests

FakeCloud by default, live only with a flag

CI installs the package and runs pytest plus gitleaks. It never sets GPUBOX_LIVE.

uv run --project . --directory . --reinstall-package gpubox pytest -q

Default tests use FakeCloud and injected vendor clients. They do not rent GPUs. Opt-in live checks snapshot existing ids first, create only with label gpubox-live-YYYYMMDD, and destroy only ids created in that run. They skip if the cheapest offer is over $0.40/hr.

Secrets Copy .env.example for local keys. Never commit .env. The library does not hold your cloud wallet.
